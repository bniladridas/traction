# Graphics: Metal on Apple Silicon

Target 1080p60. Quality presets Low/Medium/High/Ultra control resolution, shadows, effects, textures, AA.

Car: PBR + clearcoat paint, glass, rubber, brake discs.
Track: road material, grass/terrain, barriers, trees/buildings last.
Lighting: sun + skylight, shadows budgeted, reflections (SSR/cubemap), post (bloom/AO/vignette minimal).

Profile GPU/CPU time, draw calls, texture memory, shadow cost early and often.
No DirectX-only plugins. ARM-native only.
